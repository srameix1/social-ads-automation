# Instrucciones de contexto del proyecto

1. Al comenzar cada sesión, leer primero `PROJECT_STATUS.md`.
2. No leer `MEMORY.md` completo salvo que exista una necesidad concreta que no pueda resolverse con el estado breve o el código relevante.
3. Cuando sea necesario consultar la memoria histórica, leer únicamente las secciones relevantes para la tarea actual.
4. Al finalizar cada sesión, actualizar `PROJECT_STATUS.md` con hechos comprobados durante esa sesión.
5. Mantener `PROJECT_STATUS.md` breve: reemplazar el estado anterior y no convertirlo en un registro acumulativo.
6. Seguir anexando el historial a `MEMORY.md` sin borrar ni reescribir sus entradas anteriores. Si el archivo todavía no existe, crearlo solo cuando haya una entrada histórica que registrar.
