# Metodología Orangutan

## Regla Principal
ANTES de construir cualquier agente o automatización:
1. Lee la skill `biblia-agentes/biblia.md` completa
2. Analiza el cerebro de ejemplo relevante (Dani v3 o Mauri)
3. Sigue el proceso: Discovery → Arquitectura → Construcción → Revisión

## Principios (detalle en biblia.md)
- Objetivo sobre todo — cada componente tiene propósito claro
- Información verificable > creatividad — tools antes de inventar
- Humano primero — indistinguible de experto humano
- Outcome > features — resultado, no características
- Optimización basada en datos — deploy → analizar → fix quirúrgico
