# Skill: Guía de Construcción — Metodología Orangutan v4.0

## Cuándo usar
- ANTES de diseñar cualquier agente de IA o automatización
- ANTES de escribir cualquier system prompt
- ANTES de definir tool descriptions
- Cuando necesites entender la filosofía y principios de construcción

## Qué contiene

**biblia.md** — Guía completa en un solo archivo:
- Filosofía y principios core
- Anatomía de un agente (3 capas, structure flexible de prompts, tools, psicología, Frankenstein)
- Patrones de automatización (sin agente)
- Proceso de construcción (discovery, arquitectura, build, revisión)
- Errores comunes
- Referencia rápida

## Cómo usar
1. Lee `biblia.md` al inicio de cualquier proyecto
2. Analiza los cerebros de ejemplo (Dani v3 para ventas, Mauri para subworkflows)
3. Sigue el proceso: Discovery → Arquitectura → Construcción → Revisión
